# 服务器 Hero 图全量人工标注

## 结论

- 截至 2026-10-02 服务器存量 Hero 图去重后共 506 张，文件名和 SHA256 均唯一。
- 默认回归集已升级为 `reports/hero-regression/manifest.json` v5，包含 20,998 个预期字段。
- 桌型分布为443张八人桌、63张九人桌；新增410张中有62张九人桌。
- v4 的96张人工标注原样保留；新增410张使用103张四联全宽审阅页逐图核对，其中62张九人桌单独核对座位映射。

## 标注口径

每张图记录牌局阶段、公共牌、底池、当前最大下注、Hero 手牌/筹码/下注/庄位/行动标识，以及所有对手的座位、状态、筹码和当前下注。全局 OCR 结果只用于生成草稿，最终值以原图像素的人工判断为准。

人工复核中已显式修正95张草稿，主要涉及被 OCR 遗漏的 folded 玩家筹码、Hero 筹码、空座状态和小盲注 `1`。回放过程发现人工草稿与原图冲突时，重新查看原图后修正；不会为了让当前识别实现通过而改写标签。

## 可复现性

- 图片本体不进入 Git；manifest 记录原文件名与 SHA256，回归脚本在执行前对缺失、重名和哈希不一致直接失败。
- 使用 `python scripts/check_hero_images.py --images <图片目录> --output <输出目录>` 串行回放，按完整字段比较输出。
- 当前 manifest SHA256 需在标注收口提交后以 Git blob 内容重新计算；后续任何标签调整都必须附原图复核证据。

## 数据边界

这套标注覆盖截止盘点时服务器上实际留存的 Hero 图，可用于当前 UI 的回归与 A/B 比较。它不代表所有可能的分辨率、新 UI 皮肤或未出现过的牌局状态；服务器新增 Hero 图需按同一口径增量标注。
